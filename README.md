# Create: Better Computer (CBTC)

一个基于 NeoForge 1.21.1 的机械动力（Create）附属模组：用积木搭程序的 **CB电脑**，附带拓展模块、外设绑定、无线红石、局域网 / 互联网通信、齿轮箱控制、无线显示、网络音乐与航空学联动。

版本：1.1.3（正式版）

## 能做什么

- **积木编程**：事件、控制、数据、运算、机械动力、广播、局域网、互联网、显示、航空学、声音共 11 类积木，支持拖拽拼接、分支、复制粘贴；频道选择器带搜索框，装了 Just Enough Characters 时支持拼音检索。
- **控制机械动力**：CB编程齿轮箱、智能转速控制器、无线红石收发信（含持续保持的无线红石开关 / 线缆开关）、仓储查询与打包机发货。
- **联网**：局域网内多台电脑通信，全服共享的互联网频道与聊天框收发。
- **扩展外设**：打字机、音响、讲解石、导航台、定位模块、结构图解传感器、信息转发器、枪式遥控器、枪炮手的瞄准组件。
- **火控单位**：哨戒动力臂与本模组的智能炮座 / 智能固定炮座共用一套火控积木；「火控单位瞄准」只有一个「瞄准目标」凹槽，可嵌入准星处 / 水平垂直角度 / 准星偏移三种瞄准目标，组装后由红石开火。
- **加农炮联动**：智能炮座与智能固定炮座复刻 Create Big Cannons 的火炮底座，改色贴图、无传动轴，可由 CB 电脑瞄准；支持被原版动力臂与瓦列里中士装填，也支持漏斗 / 管道输入弹药。
- **瓦列里中士**：可编程火炮装填动力臂，五行「填充 / 留空」指令自动从下方容器取弹，按程序把弹头与发射药装进装有速射炮闩的火炮，可绑定多门并按分配方法轮换。
- **配套玩法**：捏塑创生之手把生物捏成计算机零件，烈焰蛋糕把烈焰人变成超级烈焰人；大力神引擎由九轮序列组装产出，是瓦列里中士的核心材料。

## 安装

1. 安装 NeoForge 21.1.228+（Minecraft 1.21.1）与 Java 21。
2. 把前置模组放进 `mods/`：**Create 6.0.10**、**Create Aeronautics 1.3.2**、**Sable 2.0.6**。
3. 把 `cbtc-1.1.3.jar` 放进 `mods/`。
4. 可选：JEI（查看捏塑与配方）、Curios（磁石挂件放任意饰品槽）、网络音乐机（网络歌曲积木）。

## 构建

本仓库不附带任何第三方模组文件，`libs/` 默认为空。构建前请按 [libs/README.md](libs/README.md) 的清单，把前置依赖按同名文件放入 `libs/`。

```bash
# Windows
gradlew.bat build

# macOS / Linux
./gradlew build
```

构建产物位于 `build/libs/cbtc-1.1.3.jar`。

## 目录结构

```
src/main/java        # 模组源码
src/main/resources   # 资源文件（assets / data）
src/main/templates   # neoforge.mods.toml 模板
docs/                # 玩家手册
libs/                # 构建所需的前置依赖，需自行下载，见 libs/README.md
local-maven/         # DevLaunch 本地仓库
```

## 兼容性声明

**哨戒动力臂属于非官方兼容。** Create: Sentry Mechanical Arm 官方版本目前尚未发布 1.21.1 版本，本模组对该动力臂的接管（瞄准、开火、换弹、弹药读取）是基于社区在 1.21.1 上的非官方移植版本实现的。待上游发布官方 1.21.1 版本后，本模组会跟进适配官方接口；在此之前，这部分功能请以上游社区版本为准。

本模组的智能炮座 / 智能固定炮座依赖 Create Big Cannons，未安装时相关方块与积木不会注册，其余功能照常可用。
