# CB电脑 · 玩家手册

> 模组：Create: Better Computer（CBTC）　版本：1.0.0
> 适用于 Minecraft 1.21.1 / NeoForge 21.1.228+ / Create 6.0.10

---

## 1. 这是什么

CB电脑是一台**用积木搭程序**的控制台。把它放在基地里，拖几块积木，就能让它：

- 控制机械动力的齿轮箱、转速控制器，读取应力 / 转速；
- 收发无线红石信号、查询仓储网络、让打包机发货；
- 在聊天框说话、和局域网 / 全服其他电脑通信；
- 播放音效与网络歌曲、在无线显示器上写字；
- 读取航空学导航台的坐标、距离与方位。

一台电脑运行一份程序，程序保存在方块里，关机后停止运行。

## 3. 五分钟上手

1. **做出 CB电脑**：用机械动力的机械合成台，按第 8.1 节的 5×5 图案合成。
2. **放下电脑**：放下后是关机状态（屏幕暗）。
3. **潜行 + 右键**开机，屏幕亮起，程序开始运行。
4. **右键**电脑打开编程界面。
5. 从左侧积木栏拖出「当此电脑运行时」，再把要执行的积木拖到它下面，会自动吸附成串。
6. 点右上角「保存并返回」。
7. 需要更多功能时，做一张 **CB拓展器** 贴到电脑**正后方**（正面朝向电脑），右键打开，插入模块卡。

> 电脑默认关机，不放程序也能开机，只是什么都不做。

## 5. 方块图鉴

### 5.1 CB电脑

- 右键：打开编程界面；潜行右键：开机 / 关机。
- 程序只在开机时运行；关机后「本机变量」清空。
- 自带发声能力（默认 12 格，装扬声器升级模块卡后 50 格）。

### 5.2 CB拓展器

- 必须放在电脑**正后方**，让正面朝向电脑；两者分开后模块失效。
- 6 个升级模块槽位，**模块卡决定左侧栏会出现哪些积木**。
- 底部状态栏显示已连接外设与模块状态。
- 取出模块卡后，对应积木立刻从左侧栏消失；已搭好的积木保留但不执行。

### 5.3 CB音响

- 决定电脑发声的**位置**，自身发声范围 20 格，装入扬声器升级模块卡后 80 格。
- 右键打开唯一的升级槽。
- 需要用外设绑定模块卡绑定，之后「播放声音」「默念」「播放网络歌曲」才能指定由它发声。

### 5.4 讲解石（9 种材质）

- 圆石 / 安山岩 / 深板岩 / 石砖 / 花岗岩 / 苔石 / 苔石砖 / 闪长岩 / 石头。
- 用法与 CB音响 相同，但**范围固定 6 格、没有升级槽、右键不打开界面**。
- 适合当场景里的固定音源。

### 5.5 CB打字机

- 空手右键开始输入，再右键一次结束。
- 被 CB 电脑「接管」后无法自行编辑，需用绑定卡处理。
- 按键触发「当CB打字机按下」，另有「打字机按下中」「当打字机长按某键时」等积木。

### 5.6 CB编程齿轮箱

- 外观与传动沿用机械动力的序列齿轮箱，**输入端没有输出时也跟随输入应力转动**。
- 转速、转向、角度完全由积木控制，右键**不会**弹出序列界面。
- 由「控制齿轮箱」「停止齿轮箱」「齿轮箱角度」驱动。
- 零点由「齿轮箱角度标定器」右键标定，角度积木读到的都是相对零点的角度。

### 5.7 原版编程齿轮箱

- 复刻的原版可编程齿轮箱，**保留右键的序列配置界面**，走原版计时逻辑，不与积木交互。
- 用途：作为对照 / 装饰，暂无合成配方。

### 5.8 CB结构图解传感器

- 输出航空学结构的多项力学数据：质量，重力 / 阻力 / 浮力 / 气球升力 / 推进力 / 机翼推力 / 磁力的总量与 X·Y·Z 分量。
- 通过「读取外设」积木取值（需外设绑定模块卡）。
- 暂无合成配方。

### 5.9 信息转发器

- 用显示链接器把信息源的数据**按行**写进来。
- 用外设绑定模块卡绑定后，电脑的「信息获取」积木可按行读取（纯数字会自动变成可运算的数值）。

### 5.10 智能转速控制器

- 只占一格，输入端接入应力后，按设定转速从输出端输出。
- 可用外设绑定模块卡绑定，在电脑里用「设置转速控制器」设定转速、用「转速控制器的输出转速」读取。
- 也可以直接在方块上滚动调节。

## 7. 捏塑与超级烈焰人

### 7.1 捏塑创生之手

1. 先做**未充能**版本（黄铜手 + 下界之星，序列组装，70% 成功）。
2. 雷雨天把它放在**避雷针下**，等待闪电劈中，完成充能。
3. 手持**已充能**的手右键生物，生物被捏成对应零件，消耗 1 次使用次数。
4. 耐久条显示剩余次数，**总共 32 次**，用尽后变回未充能状态，需要再次充能。

| 目标生物 | 产出 |
| --- | --- |
| 烈焰人 | 烈焰人计算芯片 |
| 超级烈焰人 | 烈焰人超算单元 |
| 旋风人 | 旋风人散热器 |
| 悦灵 | 悦灵声卡 |
| 潜影贝 | 潜影贝芯片 |

安装 JEI 后可在「捏塑」分类里查到全部对应关系。

### 7.2 超级烈焰人

- **转化**：手持烈焰蛋糕右键烈焰人。
- **强化**：火球伤害翻倍（5 → 10），命中后着火 20 秒。
- **掉落**：被玩家击杀时掉落 0–1 根超级烈焰棒，受抢夺加成。
- **刷怪笼**：把烈焰蛋糕喂给烈焰人刷怪笼，30 秒内持续生成超级烈焰人，之后恢复普通。

### 7.3 药水与燃料

- 酿造：**粗制的药水 + 超级烈焰粉 → 力量药水（III，3:00）**；加红石延长到 8:00，加萤石粉强化为力量 IV（1:30）。
- 燃料：超级烈焰棒、超级烈焰粉都可以作为烈焰人燃烧室的超级燃料。

## 9. 积木图鉴

积木分 11 类：事件、控制、数据、运算、机械动力、广播、局域网、互联网、显示、航空学、声音。

### 9.1 事件

| 积木 | 说明 |
| --- | --- |
| 启动时 | 电脑开机时触发一次 |
| 当此电脑运行时 | 同一类入口，最常用 |
| 当 … 时 | 条件由不成立变为成立的那一刻触发一次；条件持续成立时，每来一条新聊天也会重新触发 |
| 收到广播 | 本机内广播 |
| 当收到局域网广播 / 互联网广播 | 局域网 / 全服频道 |
| 当收到频道信号 / 当接收到频道信号且满足强度条件 | 无线红石；后者可再要求强度（需无线红石收发信模块卡） |
| 当CB打字机按下 / 当打字机长按某键时 | 由 CB打字机 触发：按下触发一次，按住超过 0.2 秒转每刻触发；长按积木前 0.2 秒不响应 |
| 当聊天框出现文字 | 聊天框出现任意文字时成立（需互联网模块卡） |

### 9.2 控制

| 积木 | 说明 |
| --- | --- |
| 重复执行 | 一直循环，靠「退出循环」结束；每轮之间有 **1 刻内置冷却**，防止卡死服务器 |

| 重复执行直到 | 条件成立时停止 |

| 保持等待直到 | 条件成立前停在本积木 |
| 等待…秒 | 按所选单位换算成刻 |
| 退出循环 | 立即跳出最内层循环 |

## 11. 注意事项

- **循环有冷却**：所有循环每轮间有 1 刻冷却，写死循环也不会卡死服务器。
- **如果/否则只判断一次**：需要持续检测请放进「重复执行」里。
- **关机不运行**：电脑默认关机，程序只在开机时跑；关机后本机变量清空（硬盘变量保留）。
- **拓展器要贴着背**：电脑与拓展器分开后模块全部失效，拆之前先把模块卡取回。
- **模块卡决定积木**：积木不出现时先看拓展器里有没有对应模块卡。
- **打字机被接管后不能自行编辑**：避免和电脑的按键读取冲突。
- **局域网密码先到先得**：同一 ID 首次输入的密码即注册密码。
- **互联网全服唯一**：一个存档里只有一份互联网。

## 12. 常见问题

**Q：积木栏里没有局域网 / 互联网 / 音乐积木？**
A：对应模块卡没插在拓展器里，或拓展器没贴到电脑背面。

**Q：电脑开机了但程序不执行？**
A：检查入口积木是否为「当此电脑运行时」；再看程序是否保存成功（保存并返回）。

**Q：播放声音没反应？**
A：声音范围受设备限制；指定的 CB音响 / 讲解石是否已绑定、是否在同一维度附近。

**Q：齿轮箱不动？**
A：确认齿轮箱有应力输入（输入端接传动轴），并且已用外设绑定模块卡绑定。

**Q：捏塑之手用不了？**
A：未充能的手需要雷雨天在避雷针下被闪电劈中；已充能的手用完 32 次会变回未充能。

**Q：仓储积木报错 / 没数据？**
A：模块卡要先用右键绑定到机械动力的仓储链接站；物流网络要有库存清单。
